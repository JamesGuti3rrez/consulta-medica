# Cuestionario SUS: Paciente Virtual Adaptativo

Responda después de completar **una consulta completa** en el simulador: entrevista, exámenes y diagnóstico final.
Marque de **1** («totalmente en desacuerdo») a **5** («totalmente de acuerdo»). Si no sabe qué responder, marque 3.

| # | Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Creo que me gustaría usar este simulador con frecuencia. | | | | | |
| 2 | Encontré el simulador innecesariamente complejo. | | | | | |
| 3 | Pensé que el simulador era fácil de usar. | | | | | |
| 4 | Creo que necesitaría el apoyo de un técnico para poder usar este simulador. | | | | | |
| 5 | Encontré que las diversas funciones del simulador estaban bien integradas. | | | | | |
| 6 | Pensé que había demasiada inconsistencia en el simulador. | | | | | |
| 7 | Imagino que la mayoría de las personas aprendería a usar este simulador muy rápidamente. | | | | | |
| 8 | Encontré el simulador muy engorroso de usar. | | | | | |
| 9 | Me sentí muy seguro/a usando el simulador. | | | | | |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar este simulador. | | | | | |

Datos del participante (no se registran nombres): código (P01, P02...), rol (estudiante o docente) y ciclo.

**Cómo registrar:** una fila por participante en `sus_respuestas.csv`. Las filas que empiezan con `#` son
ejemplos y no se cuentan. Para un piloto mínimo, apunten a **n ≥ 8**. Con n = 5 ya aparecen la mayoría de los
problemas de usabilidad (Nielsen), pero el intervalo de confianza de la media queda muy ancho.

Si hacen el formulario en Google Forms, usen exactamente estas 10 afirmaciones en este orden. Luego descarguen
el CSV y copien las columnas a `sus_respuestas.csv`.
