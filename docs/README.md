| `agents/` | Roles, contexto permitido por rol y orquestación. |

| `testing/` | Estrategia de pruebas, evals y criterios de aceptación. |
| `development/` | Instalación, convenciones, variables de entorno y despliegue. |
| `reference/` | Documentos de diseño del proyecto. |
