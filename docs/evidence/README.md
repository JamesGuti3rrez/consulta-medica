# Evidencia: catálogo curado en el simulador

La captura [simulador-caso-curado.png](./simulador-caso-curado.png) documenta la carga de un
expediente curado en la ficha del simulador. Esta captura se tomó en **vista de escritorio/PC con
1440 px de ancho**, no en vista móvil. Se comprobó en el navegador local: la API informó diez casos
disponibles, el botón cargó un expediente y la pantalla mostró solo datos públicos del caso.

Todas las evidencias visuales de este proyecto deben capturarse en vista de escritorio/PC; no usar
vista móvil ni emulación de teléfono.

La captura no acredita una conversación clínica interactiva: los turnos, la evaluación del alumno y
el guardado de intentos continúan pendientes.

Para repetir la prueba, iniciar el backend y abrir `/simulacion.html`; luego seleccionar
**Iniciar simulación demo**.
