# reference/

Documentos de diseño del proyecto que sirven de referencia para el desarrollo. Los originales están en los materiales del proyecto; si se desea versionarlos, colocarlos aquí sin modificarlos.

| Documento | Tema |
| --- | --- |
| Arquitectura_Paciente_Virtual | Arquitectura v1.0 y decisiones |
| Respaldo_Diseno_Esquema_JSON | Justificación del esquema oficial |
| TA-001 Informe Técnico del Prototipo | Estado de la interfaz, accesibilidad y despliegue actuales |
| Paciente_Virtual_Adaptativo, Trasfondo_Tecnico_Proyecto | Descripción y propuesta técnica inicial |

Los informes de las pruebas de funcionamiento (RAG, agentes, aislamiento, anclaje, conversión de datasets, pipeline) no forman parte del proyecto y no se incluyen aquí.

**Atención:** los archivos con extensión `.docx` son en realidad texto Markdown renombrado; Word no los abre. Conviene guardarlos como `.md` o regenerarlos como Word real.
